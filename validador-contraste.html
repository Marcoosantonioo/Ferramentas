Perguntas frequentes

Como testar o contraste de cores? +

Há dois métodos para realizar o teste: usando o conta-gotas para capturar cores diretamente da tela, ou inserindo os códigos HEX manualmente. Ambos atualizam o resultado em tempo real.

Método 1 — Conta-gotas (captura visual)

1

Clique no quadrado colorido ao lado do campo "Cor do Texto" para abrir o seletor.

2

Clique no botão "Conta-gotas" dentro do seletor. O popover fecha e o cursor muda para o ícone de conta-gotas. Este recurso está disponível apenas no Chrome e no Edge. No Firefox e no Safari o botão não aparece; nesses navegadores, use o Método 2 (código HEX).

3

Clique sobre o texto que deseja avaliar em qualquer ponto da tela. A cor é capturada automaticamente e o campo HEX é preenchido.

4

Repita o processo para a "Cor do Fundo", capturando a cor de fundo do elemento avaliado.

5

A razão de contraste e os resultados WCAG 1.4.3 são exibidos automaticamente. Verifique se o critério exigido (AA Normal ou AA Grande) indica Passa.

Método 2 — Código HEX (inserção manual)

1

Obtenha os códigos HEX das cores no Figma, no código-fonte (CSS/tokens) ou na ferramenta de inspeção do navegador (DevTools).

2

Digite ou cole o código no campo "Cor do Texto" no formato #RRGGBB, por exemplo #1F2937. Também são aceitos códigos curtos, como #FFF.

3

Repita para o campo "Cor do Fundo" com a cor de fundo do componente avaliado.

4

A razão de contraste é calculada assim que o código estiver completo. Confirme se o resultado atende ao critério WCAG 1.4.3: mínimo de 4,5:1 para texto regular ou 3:1 para texto grande.

Qual é a finalidade de um verificador de contraste? +
Um verificador de contraste existe para garantir que o texto seja legível para todos os usuários, em especial para pessoas com baixa visão ou daltonismo. Ele calcula a diferença de luminosidade entre a cor do texto e do fundo.
O que são as WCAG e por que elas são importantes para o contraste? +
As WCAG (Web Content Accessibility Guidelines) são diretrizes internacionais que definem como tornar o conteúdo web mais acessível. Elas estabelecem regras matemáticas de contraste mínimo.
Qual é a taxa de contraste ideal? +
Segundo as WCAG nível AA, a taxa mínima é de 4,5:1 para textos regulares e 3:1 para textos grandes (≥ 18pt ou ≥ 14pt negrito).
